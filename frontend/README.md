# Frontend (MeuRachão)

Scaffold mínimo: React + TypeScript + Vite (SPA)

Como rodar (Windows PowerShell):

```powershell
cd C:\Users\Brayan\Documents\repositories\app-meu-rachao\frontend; npm install
npm run dev
```

- `npm run dev` — inicia o Vite (dev server)
- `npm run build` — gera a build de produção em `dist/`

Observações:
- A escolha foi Vite por ser rápida e adequada para SPA modernas.
- Apenas um Hello World e estrutura de componentes criada em `src/components/`.
