# Backend (MeuRachão)

Scaffold mínimo: Node (LTS) + TypeScript + Express

Como rodar (Windows PowerShell):

```powershell
cd C:\Users\Brayan\Documents\repositories\app-meu-rachao\backend; npm install
npm run dev
```

- `npm run dev` — inicia o servidor em modo dev (ts-node-dev)
- `npm run build` — compila TypeScript para `dist/`
- `npm start` — executa `dist/index.js` (após build)

Observações:
- Projeto segue separação: `src/` para código TypeScript. Apenas um endpoint Hello World foi criado.
